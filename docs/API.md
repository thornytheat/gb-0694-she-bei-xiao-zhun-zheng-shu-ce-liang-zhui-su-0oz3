# 接口

`POST /api/run`：JSON中的csv文本，省略使用样例；或multipart字段file。最大5MB。

`POST /api/m1`至`POST /api/m8`：独立运行到指定模块，JSON结构同运行接口。

`GET /api/history`：历史批次。`POST /api/review`接收id、revision和decision（通过或退回）。`GET /api/evidence.csv`提供单一证据导出，M8批次额外导出“8-校准点”明细（含采信与否、原因码、所属计划编号）。`GET /api/runs/<id>/plans`读取批次生成的校准计划，计划编号由设备、末次校准日与间隔确定性派生，同批重跑不重复生成。

结构错误422，版本变化409，文件过大413；错误返回code与message。所有页面可从左侧七个模块入口访问。

`GET /api/runs/<id>`读取指定批次；页面与证据CSV通过run_id查询参数绑定批次，模块导航保留该参数。

JSON请求体必须是对象，数组、标量、null、损坏JSON及错误上传字段返回400，且不运行默认样例。

## M8 校准间隔建议

仅M6裁决“可采用”的校准点计入稳定证据；撤销（REVOKED）、超量程（OUT_OF_RANGE）、溯源中断（MISSING_REFERENCE等）与失效窗口记录只保留在校准点明细中，标记“采信=否”，不参与统计。同一设备的旧编码与别名经M2并查集归并到同一台设备后再统计。

间隔阶梯为3/6/12月，下次校准日=末次有效校准日加建议间隔（日历月，月末钳制）。决策阈值固化在运行清单`manifest.parameters`：延长需≥4个有效点且历史跨度≥240天、失效证据占比<50%、无单步波动超全量程10%；全部非零步同号且累计漂移≥全量程10%判连续单向漂移，缩短到3月；最新点距容差边界≤全量程10%（仅全量程≤20V仪器）判接近容差，缩短到3月；偶发波动已回落维持6月；无任何有效点按3月管控。上游CSV更新后内容哈希变化即生成新批次并整体重算，计划随批次幂等复用。
