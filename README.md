# 设备校准证书与测量追溯

检验机构质量员使用本工具完成：合并仪器使用与校准证书，裁决测量是否在有效可追溯链内。

## 业务

证书有效期与量程双约束；参考标准也须在校准时有效，证书撤销向下游传播并检测环。八个模块：证书接收、设备别名、有效区间、量程匹配、溯源链路、测量裁决、撤销复核、间隔建议。模块独立API及页面入口见docs/API.md。样例中包含真实常见脏数据，原因码和原始行号在隔离面板及证据文件中可复核。

## 校准间隔建议（M8）

`sample_data/calibration_history.csv` 是历次校准记录样例，覆盖长期稳定、连续单向漂移、偶发波动、接近容差、旧编码归并及撤销/超量程/溯源中断。M8 只采信 M6 裁决“可采用”的校准点：长期稳定（≥4点、跨度≥240天、无显著波动）延长到12个月；连续单向漂移或最新点接近容差缩短到3个月；偶发波动已回落或历史不足维持6个月；无有效证据按3个月管控。每台设备输出建议间隔、下次校准日（末次校准日加间隔，日历月钳制）与含实际量值和阈值的变动依据；页面与证据CSV可查每个计划采用的校准点。上游记录更新后内容哈希变化即整体重算为新批次，同批重跑复用批次且plans表唯一约束保证不重复生成计划。

## 启动与验证

```sh
docker compose up --build -d
docker compose exec -T app pytest -q
docker compose config --quiet
```

打开 http://localhost:18208 。点击“运行样例”，或展开输入区提交CSV。切换七个模块查看计算依据。复核区可通过或退回，同一版本仅允许一次复核。证据CSV包含所有阶段与隔离行，批次内容不因复核变更。

SQLite保存在命名卷records；容器重建保留历史。只在确认不再需要数据时执行 `docker compose down -v` 重建。端口可通过.env中的PORT调整。本地也可 `pip install -r requirements.txt` 后 `python -m app.main`。

## 定义与限制

详见docs/DATA-DICTIONARY.md、docs/DEPTH.md。单文件最大5MB/一万行，本工具按确定性文件离线复算，不查询外部业务系统。源码位于app，测试位于tests，样例位于sample_data。
